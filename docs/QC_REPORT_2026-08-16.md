# Animal data QC report — 2026-08-16

## Scope and result

- Audited all 426 published animal JSON records and all published image files.
- The default release gate passes: schema, uniqueness, controlled tags, taxonomy shape, bilingual required fields, IUCN labels, map coordinate shape, image existence/type/hash duplication, lint, TypeScript, and production build.
- This is a structural and targeted factual audit. It is **not** a claim that every sentence in the 426 legacy encyclopedia entries has been independently source-verified.

## Corrected data

- Corrected 5 scientific names: Blue-footed Booby (`Sula nebouxii`), Giraffe Stag Beetle (`Prosopocoilus girafa`), White-winged Vampire Bat (`Diaemus youngii`), Indian Flying Fox (`Pteropus medius`), and Yangtze Finless Porpoise (`Neophocaena asiaeorientalis`).
- Corrected the English name of Philippine Flying Lemur and the Chinese kingdom label for Thorn Bug.
- Corrected 13 IUCN categories: Green Sea Turtle, Bearded Bellbird, Black-backed Kingfisher, Boulder Brain Coral, Chinese High-fin Banded Shark, Grooved Brain Coral, Indian Flying Fox, Koala, Pacific Angelshark, Red-crowned Crane, Saiga Antelope, Swan Goose, and Wild Bactrian Camel.
- Canonicalized all IUCN labels across the 9 official category codes used by the project. Kept “possibly extinct” as a note instead of inventing a non-IUCN category, and moved CITES Appendix II out of the IUCN field.
- Normalized 244 records to the controlled `[Class, Habitat, Diet]` tag vocabulary.
- Repaired 98 map records. Polygon count changed from 830 to 706 after removing unsupported bounding boxes and repairing invalid or unclosed rings. When reliable geometry is unavailable, the UI now shows only a point marker.

## Image audit

- Approved 12 exact-species, openly licensed replacement images after visual review. Each has source URL, taxon ID, photo ID, attribution, license, dimensions, SHA-256 hash, and review timestamp in `data/image-attribution.json`.
- Removed duplicate image content from the published set.
- Moved the orphan `chameleon.jpg` to `public/images/quarantine/`.
- Hid and quarantined the old King’s Box Jellyfish image because it could not be verified to species level.
- Three relevant but low-resolution legacy images remain marked `replacement-needed`: Baiji, Cebu Flowerpecker, and Ili Pika.

## Explicit remaining provenance gaps

- 410 legacy images are marked `legacy-unverified`; they passed file integrity and duplicate checks but do not yet have verified open-license provenance.
- The 3 `replacement-needed` images and 1 `hidden-unverified` image also lack approved replacement provenance. Therefore only the 12 newly approved images currently satisfy the strict image-source standard.
- All 426 legacy text records are marked `legacy-structure-checked`. Key names/statuses and required fields were audited, but the long-form descriptions still need per-claim citations before they can be described as fully source-verified.
- The 706 retained legacy polygon rings pass geometric validation, but do not yet have per-polygon source metadata.

These gaps are deliberately visible rather than silently treated as complete. New records cannot be finalized by the automated wishlist workflow until their JSON passes validation and their image has explicit human approval plus verified license metadata.

```bash
npm run validate:data

```
